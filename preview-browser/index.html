No internet required after installation

How to add Still to your device

Android (Chrome): Open the hosted website, then select Install app or Add to Home screen from the browser menu.

iPhone/iPad (Safari): Open the hosted website, tap Share, then Add to Home Screen.

Computer (Chrome/Edge): Open the hosted website and select Install from the address bar or browser menu.

Offline ZIP: Extract these files and double-click index.html whenever you want. A true installed app requires serving Still from an HTTPS website (or localhost for testing).
